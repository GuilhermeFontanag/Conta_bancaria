Sistema de Conta Bancária
Este repositório contém uma aplicação desenvolvida para simular e gerenciar operações básicas de uma Conta Bancária, incluindo depósito, saque, consulta de saldo e extrato de transações.

Funcionalidades
Criação e Gestão de Conta: Cadastro de titular e número da conta.

Depósitos: Adição de valores ao saldo da conta com validação de entradas.

Saques: Retirada de valores respeitando o limite de saldo disponível.

Consulta de Saldo: Exibição do valor atualizado na conta.

Extrato: Histórico simplificado de operações realizadas.

Como Executar o Projeto
Possuir a versao do JDK25 em sua maquina e dar start
